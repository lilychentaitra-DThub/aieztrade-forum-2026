## 觀看

## 操作

| 動作 | 按鍵 |
|---|---|
| 下一頁 | `→` / `↓` / `Space` / `PageDown` |
| 上一頁 | `←` / `↑` / `PageUp` |
| 首頁 / 末頁 | `Home` / `End` |
| 講者備註開關 | `N` |
| 全螢幕 | `F` |

第 11、16 頁的印章是獨立的一拍：翻到該頁不會自動出現，再按一次方向鍵才蓋下來。

## 技術說明

- 單一 HTML 檔，無外部相依套件，離線可用（字型 fallback 到系統的微軟正黑體／PingFang TC）
- 橫向 scroll-snap 換頁，`prefers-reduced-motion` 下自動關閉所有動態
- 第 04 頁的 `trobo-demo.mp4` 翻到該頁自動靜音播放，離頁暫停並倒回開頭
