## 技術說明

- 單一 HTML 檔，無外部相依套件，離線可用（字型 fallback 到系統的微軟正黑體／PingFang TC）
- 橫向 scroll-snap 換頁，`prefers-reduced-motion` 下自動關閉所有動態
- 第 03 頁的 `trobo-demo.mp4` 翻到該頁自動靜音播放，離頁暫停並倒回開頭
- 第 13 頁的趨勢折線圖是 inline SVG，不是圖檔
- 圖檔一律用 ASCII 檔名，避免 GitHub Pages 上中文路徑的編碼問題
